How to run it
  1. Before class: add one file per group, then encrypt. Print the code slips or keep the codes.
  2. At the start of class: play the stream fullscreen on the projector. Students receive it from their seats. Those who finish can share it with their neighbours.
  3. When everyone shows Quiz received: hand out the slips, or show a code on screen. Everyone opens the quiz at the same moment.

1 · Quiz and groups

Each group gets its own file and code. Use one group if everyone takes the same quiz. Every phone receives all versions, so the total size sets the time: at the default settings about 30 s per 100 KB in total, for seats within a few metres.

Broadcast settings

Smaller blocks or fewer frames per second make bigger QR modules that read from farther away, but the transfer takes longer. The defaults aim at about 30 s per 100 KB.
