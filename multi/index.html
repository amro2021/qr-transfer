2 · Layers

The base layer carries few bytes per frame, so keep its file small: under about 1 KB, such as a text message. The enhancement layer can be larger. Receivers need a sharp, close view to recover it.

Transmission settings

A smaller QR size has bigger squares and reads from farther away, but carries less per frame. With 2 or 4 tiles each code is drawn smaller, so choose a smaller level. The frame rate changes live while playing.

The screen cycles through all 7 QR sizes, about a second each. Receivers open the Receive tab and camera; each phone shows the largest level it reads reliably.
